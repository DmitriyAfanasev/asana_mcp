# Asana MCP

Личный MCP-сервер для работы с Asana через ассистента. Сервер подключается к Asana по API и отдаёт инструменты для просмотра и изменения задач.

## Что умеет

- показывать мои задачи и задачи секции;
- показывать проекты и секции проекта;
- создавать задачи и подзадачи;
- переносить задачи между секциями;
- отмечать задачи выполненными или возвращать их в работу;
- назначать задачу пользователю, забирать её себе и удалять задачу.

## Установка и настройка

Нужны Python 3.13+ и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
cp .env.example .env
```

В `.env` укажите персональный токен Asana:

```env
ASANA_PAT=ваш_персональный_токен_Asana
```

Токен можно создать в настройках Asana: **My Settings → Apps → Personal access tokens**. Файл `.env` не коммитится в Git.

## Запуск

Для запуска из терминала:

```bash
export ASANA_PAT="ваш_токен"
uv run python -m asana_mcp
```

Сервер работает в режиме `stdio`: после запуска он ждёт MCP-запросы, поэтому в терминале обычно не выводит обычный интерфейс. Логи идут в `stderr`.

## Подключение к MCP-клиенту

В настройках клиента добавьте сервер с командой `uv`. Например:

```json
{
  "mcpServers": {
    "asana": {
      "command": "uv",
      "args": [
        "run",
        "--directory",
        "/home/mister/PycharmProjects/my_mcp",
        "python",
        "-m",
        "asana_mcp"
      ],
      "env": {
        "ASANA_PAT": "ваш_персональный_токен_Asana"
      }
    }
  }
}
```

Замените путь к проекту и токен на свои значения, перезапустите MCP-клиент и попросите ассистента, например:

```text
Покажи мои активные задачи в Asana.
Создай задачу «Подготовить отчёт» со сроком 2026-10-01.
Покажи проекты и перенеси задачу <gid> в секцию «В работе».
```

Для операций, где нужен идентификатор проекта или задачи, сначала попросите ассистента вывести проекты или задачи — MCP вернёт необходимые `gid`.
